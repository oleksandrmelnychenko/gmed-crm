# Cabinet → admin wizard parity

Дата перевірки: 2026-10-12. Фінальний стан продуктового коду та опублікованого DEV: `6cda9349183326b3194e5a68d5257e150ab2c2bf`. Після публікації повторно звірено чинний main, типи форм та live admin API контракт.

## Межі та результат

Цей звіт звіряє **8 конкретних пунктів наданого переліку** та пов’язані з ними джерела полів сучасного кабінету. Оригінального `qa/cabinet-to-wizard-matrix.md` немає в обох checkout та початковому workspace; висновок про повну перевірку «113 полів» не робиться.

У коді закриті всі 8 пунктів. DEV пакет `6cda9349` опубліковано 2026-10-12 о 19:27 UTC: міграційна репетиція пройшла для 467 наявних і 2 нових міграцій, health відповідає HTTP 200, образи працюють. Read-only live перевірка `/leads/{id}/portal-intake` також дала HTTP 200 та підтвердила наявність `consent_form`, `payer_organisation`, `billing.via_third_party_kind`, `billing.recipient_updated_at` і `enhanced_details.relationship_proof_requested`.

Це підтверджує **опублікований контракт API**, маршрути даних, умови відображення та синтетичні сценарії. Наявність ключа, зокрема з `null` через permissions або відсутню відповідь, не доводить перенесення кожного заповненого значення. Повний live roundtrip «113 полів» від заповнення кабінету до всіх wizard views не проводився; без початкової матриці та набору очікуваних значень такий висновок не робиться. У звіт не додано даних конкретних осіб; API доказ містить лише ключі, а live перевірка не редагувала бізнес-дані.

## T10/T11 та очікувана сума

З 2026-10-12 сумові AML-тригери **T10 і T11 вилучені** за рішенням власника. Старі настройки читаються без їхніх points/knockout і порогів `threshold_1_eur / threshold_2_eur`, зі збереженням інших чинних налаштувань. Збережена оцінка прибирає T10/T11 при наступному reassessment; інші trigger keys, зокрема T12–T16, не перенумеровані. Кабінет більше не запитує `expected_total_eur`, а block C не вимагає його для завершення. Старе значення зберігається для читання, але не впливає на сумові тригери, яких більше немає.

Перевірка використовувала встановлений Chrome, окремий localhost та закритий API proxy; чинні дані DEV не змінювалися. Виправлення стосується лише тесту, продуктовий код залишається `6cda9349`.
- Backend: **904 server library tests passed**, 1 наявний ignored test потребує окремого isolated admin DB URL; **7/7 `lead_payer_link_api`** та **25/25 `lead_portal_api`** пройшли на disposable Docker PostgreSQL з synthetic fixtures та pool size 4. Серед перевірок — згоди без medical files, grant/revocation, named-recipient validation/read-back, actor/date/version, minor access, одноразове сповіщення при паралельних читачах, зміни після submission та invoice-recipient derivation.
- Завершальні `cargo fmt --all -- --check`, Clippy workspace/all-targets/locked із `-D warnings` та diff whitespace check пройшли. Guards даних і згод не послаблювалися.
- DEV publish: committed-only пакет `6cda9349`, migration rehearsal **467 existing + 2 pending — PASS**, нові міграції застосовані; HTTP 200 та healthy runtime підтверджені.
- Live admin API proof: локальний некомітований `.tmp/release-audit/dev-api-contract-20261012.json` фіксує source SHA, HTTP 200, `root_keys / billing_keys / enhanced_keys` і `values_omitted=true`.
