# Перевірка перекладу двосторінкового англійського звіту

Наданий користувачем PDF перевірено локально: обидві сторінки переглянуті після
рендерингу, текст і німецька чернетка зіставлені з документом. Обидві сторінки
мають текстовий шар; цей тест перевіряє видобування тексту й переклад, а не OCR
сканів. Оригінал не змінено. Документ, його текст і переклад не додані до
репозиторію або регресійних фікстур.

## Виявлені та виправлені проблеми

- Режим PDF layout вставляв пробіли всередину чисел і дат. Якщо числові токени
  різняться між режимами видобування, використовується повний plain text потік.
  Цифри не виправляються припущеннями. Табличне розташування з незміненими
  числами зберігається.
- Заголовки Report Summary, Medical Summary і Thyroid Sonography отримали
  відповідні межі розділів та німецькі назви. Згадка лабораторних результатів
  в описовому звіті більше не визначає його як лабораторну таблицю.
- Довгий список діагнозів без маркерів більше не об’єднується в один факт.
  Виключення, анамнез і поточні діагнози зберігають окремі статуси. Формулювання
  про невиявлені антитіла не стає підтвердженим діагнозом.
- Підпис і сторінка з реквізитами не продовжують останній клінічний розділ.
- Перенесені рядки прози об’єднуються перед перекладом речень. Межі сторінок,
  абзаців, заголовків, табличних клітинок і рядків діагнозів зберігаються.
- Однозначну локалізацію десяткового роздільника повернуто до написання джерела.
  Змінені цифри, переставлені числа та неоднозначні групи з трьох цифр не
  виправляються. Після цього діє строга перевірка числової послідовності.
- Додано перевірки пропуску сторони, двобічності, історичного статусу та
  виключення, а також зміни кількості підтримуваних заперечень. Фрагменти,
  що не проходять ці перевірки, недоступні для перенесення кнопкою перекладу.

## Результат повторного прогону

| Перевірка | Результат |
| --- | --- |
| Сторінки | 2 із 2, native text |
| Тип документа | medical_report |
| Числові токени в перекладі | 59 із 59, написання й порядок збігаються з джерелом |
| Клінічні кандидати | 12: 2 vital, 6 examination, 2 diagnosis, 2 anamnesis |
| Клінічні кандидати зі сторінки підпису | 0 |
| Автоматично вибрані кандидати | 0 |
| Переклади кандидатів, що пройшли технічні перевірки | 11 із 12 |
| Текстові переклади, доступні для перенесення з перевіркою | 9; структуровані vital не перезаписуються |
| Заблоковані переклади кандидатів | 1 |
| Оригінальний файл, англійська чернетка та кандидати | Не змінені перекладом |
| Час одного локального прогону | Приблизно 4,5 секунди |

Один фрагмент із назвою операції модель залишає частково англійською.
Перевірка сторони виявляє цю помилку, показує `translation_terms_changed`
і блокує перенесення фрагмента. Повний машинний переклад залишається видимим
як чернетка для зіставлення з джерелом.

Загальна модель Argos en→de 1.3 все ще дає неприродні формулювання. Перевірки
чисел і ключових слів не доводять повної медичної точності й не виявляють усіх
можливих змін змісту. Статус результату — `review_required`; цей тест не є
підставою обіцяти 100% точний переклад або автоматично підтверджувати записи.

## Регресійна перевірка

Додано 30 синтетичних тестів, включно з прогоном установленої локальної моделі.
Повний набір парсера: 245 тестів і 8 subtests пройшли. Окремо пройшли 8 тестів
оцінювача benchmark. Версія парсера: `rules-0.10.3`.

Зміни перевірені локально, не розгорнуті. Для вже створених імпортів після
розгортання потрібне повторне розпізнавання; старі чернетки не перезаписуються.
