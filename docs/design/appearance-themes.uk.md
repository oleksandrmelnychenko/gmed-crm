# Власні теми GMED

Швидке перемикання: кнопка палітри **Теми** в хедері поруч із мовою. Меню показує вбудовані й власні теми та позначає поточну. Пункт **Налаштування оформлення** відкриває секцію імпорту й експорту в акаунті. На вузькому екрані в хедері залишається лише іконка палітри.

Відкрийте **Акаунт → Оформлення → Власна тема · JSON**. Можна вставити JSON або імпортувати `.json` файл, переглянути зразок і натиснути **Зберегти й застосувати**. Збережені теми доступні поруч із іншими палітрами GMED. Експорт вивантажує поточну палітру; кнопка «Повернути GMED» відновлює початкові кольори.

Сервер зберігає вибрану тему, власні палітри та кольори для кожного акаунта. Після входу в іншому браузері завантажується оформлення цього акаунта. Браузер кешує останній вибір для швидкого відкриття.

## Готові палітри

У «Оформленні» доступні чотири вбудовані палітри.

- **Graphite** — сіра основа та графітові кнопки.
- **Orange** — помаранчевий акцент.
- **Clay** — теплі глиняні відтінки.
- **Ink** — сині чорнильні відтінки.

Кожна палітра змінює навігацію, робочу область, контролі й стани рядків таблиць. У всіх залишаються білі картки, помаранчеві маркери заголовків та семантичні кольори статусів. Будь-яку готову тему можна експортувати як основу власної.

## Формат

Готовий файл: [theme-template.json](./theme-template.json). `version`, `id`, `name`, `colors` обов'язкові. Всередині `colors` можна вказати лише потрібні зміни — решта береться з GMED Graphite. Експорт завжди містить усю палітру.

```json
{
  "version": 1,
  "id": "my-ocean",
  "name": "Ocean",
  "colors": {
    "background": "#edf2f6",
    "primary": "#143348",
    "primaryText": "#ffffff",
    "headingMarker": "#f97316",
    "sidebar": "#f6f8fb"
  }
}
```

`id`: до 48 малих латинських літер, цифр і дефісів; починається з літери або цифри. `name`: 1–64 символи. Змінюйте `id`, коли створюєте нову тему; повторний імпорт того самого `id` оновлює наявну. Ідентифікатори всіх вбудованих тем захищені від заміни. Можна зберегти до 30 власних тем. Максимальний розмір імпортованого файлу — 16 КБ.

Для кольорів у JSON використовуйте формат `#RRGGBB`. Поєднання кольорів обирає користувач.

## Межі поточної версії

Тема діє в кабінетах команди, пацієнта й ліда. Кольори семантичних статусів (успіх, попередження, помилка, інформація) залишаються окремими й не входять у палітру. Розміри, відступи, шрифти й геометрія також не змінюються.

Спільні поверхні, контролі, таблиці й модальні вікна працюють через семантичні змінні. На них також переведені локальні панелі лідів, пацієнтів, клінічного імпорту, медикаментів, документів, замовлень, провайдерів, прийомів та адміністративних форм. Поля дат, спливні календарі й вибір часу використовують ту саму палітру, включно з вибраними значеннями та фокусом. Підписи, сітка й підказки графіків також підхоплюють тему; кольори серій і семантичних категорій залишаються окремими.

Білий фон PDF, canvas і самих сканів зберігається навмисно — тема змінює оболонку перегляду, а не оригінал документа. Логотипи, QR-коди, зображення, статусні палітри та фірмові ілюстрації не перефарбовуються автоматично. Повноцінна темна тема потребує окремої міграції й перевірки цих компонентів.

## Для розробки

- Джерело формату й початкової палітри: `frontend/src/lib/appearance-theme.ts`.
- CSS-мапінг: `themeCssVariables`; `headingMarker` → `--heading-marker`, `primary` → `--primary` та сумісний `--brand`.
- Підключення: `AppShellFrame` застосовує змінні до оболонки й `document.body`, щоб діалоги через портали отримували ту саму тему. При виході/зміні області попередні значення відновлюються.
- Нові компоненти використовують `bg-card`, `text-foreground`, `border-border`, `bg-primary`, `text-primary-foreground` та інші семантичні класи, а не власні hex-кольори.
- Для полів використовуйте `bg-field`, для підписів — `text-muted-foreground`, для фокусу — `ring-ring`. Не підставляйте `text-white` до `bg-primary`: колір тексту кнопки задає `primaryText`.
- Перевіряйте власну палітру з відмінними від білого `surface` і `field`: стандартні білі картки готових тем можуть приховати локальний `bg-white`. Календарі мають клас `gmed-picker-paper`; їхній рецепт у `gmed-controls.css` діє лише всередині `.gmed-theme`, включно з порталами в `body`.
- Не використовуйте `--heading-marker` для статусних крапок успіху/помилки.
- Перевірки: `npm test -- src/lib/appearance-theme.test.ts`, `npm run typecheck`.
